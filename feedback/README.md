# feedback/ — reviewed batches

Archived feedback, one file per batch, named `YYYY-MM-DD-reviewed.md` after
the date the batch was *folded into* `SKILL.md` — not the date it was
captured.

A file lands here only after its notes have been acted on: either the
protocol changed, or the note was considered and deliberately not acted on.
The second case must say why, otherwise the same friction gets re-raised
three runs later and re-litigated from scratch.

Open, unfolded notes live in [`../FEEDBACK.md`](../FEEDBACK.md).
